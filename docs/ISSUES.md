# 待修问题

1. 行尾图片持续闪烁：`![image](<路径>)` 跟在正文行尾时，同一张图每 220ms 重新解码注入一次。而且会让正文跟着排布错误。
增加点击图片的右键跳到下面。
2. 行尾图片被排到段落文字中间，没有落在文字后面。
3. 图片按行内元素参与正文排版，没有独立成块，靠撑高行高占位。
4. 图片左边没有对齐正文首字，起始位置由固定 100 的补偿值决定，引用／列表缩进下偏差更大。
5. 图片识别只认 `![alt](url)`，`[image](xxx.png)` 不会被当成图片。
6. 中文标点紧贴粗体结束符时粗体不结束：`**历史结果（上下文）**交给大模型` 会一路并到后面那个 `**`。
7. 引用块内有换行时，左侧引用竖线被割断，不能连续贯通整段引用（行首的 `>` 表现正常）。
8. 编辑器右键菜单条目平铺、没有分组，缺少 Markdown 常用操作，`openTerminal` 创建后未加入菜单。
