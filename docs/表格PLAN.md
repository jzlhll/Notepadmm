# Markdown 表格编辑与呈现

## 解析与源码

- commonmark GFM AST 确定表格边界、列对齐和行内展示，正文与表格使用相同语法。支持缺列补空、多列截取展示、单连字符分隔、引用及列表容器。
- 每行保存独立容器前缀；超出表头列数的原始单元格继续保留，结构操作和格式化不静默删除这些内容。缺失单元格首次写入时同步补齐该行，不等待整表回填。
- 格内输入以目标行列身份同步更新源码偏移，空格首次输入及清空后重输不使用普通文本的边界平移规则。
- 单元格按 AST 的行内语义展示，`# 标题`、`---` 不作为块级元素解析；引用链接使用全文定义。
- 显式格内换行序列化为 `<br>`，代码片段、链接目标及标题、HTML 属性内的 `<br>` 保留字面含义。未修改的换行保留原标签形式，搜索使用相同的偏移映射。

## 编辑与导航

- 活动格显示 Markdown 源文，其余格显示预览。单击使用 TextAreaSkin 字符命中定位，换行不修改源码。
- Tab／Shift+Tab 切换格子，自动显露目标行与列；首尾越界进入前后正文，必要时创建正文段落并保留空白分隔行，防止后续输入被解析为表体。
- 格内输入、撤销重做、结构操作使用主文档撤销链。结构操作立即废弃旧行列范围，等待解析及布局回填后恢复编辑；期间的撤销重做按顺序延后执行。
- 输入法组合输入期间不执行格式快捷键；切换格子和结构操作等待组合完成。
- 只读时允许选择、复制和形态切换；输入、格式修改和撤销重做入口统一检查只读状态。
- 右键菜单提供格内剪切、复制、粘贴、全选、撤销重做、复制当前行及删除当前行列。表头不可删除，至少保留一列。
- 工具栏提供末尾增行、末尾增列、优化表格、源码／表格切换和退出到表格后。源码形态可以继续直接编辑。

## 结构编辑与粘贴

- 右键在当前数据行上方／下方插入行，在当前列左侧／右侧插入列；表头上方不插入数据行。Cmd/Ctrl＋Enter 在当前行下方插入。
- 当前列可设为左对齐、居中、右对齐，写回 Markdown 分隔行；新增列采用默认对齐。
- 含制表符的剪贴板内容按 TSV 从当前格向右、向下覆盖，空间不足时扩充行列；支持引号包裹的换行、制表符和双引号转义。未覆盖的格子保留。TSV 按普通文字导入，转义 Markdown 标记、HTML 和实体，并保留格内首尾空白。
- 「粘贴为多个单元格」也支持仅用换行分隔的单列内容；「粘贴到当前单元格」和 Cmd/Ctrl＋Shift＋V 保留格内粘贴行为。
- 非 TSV 的普通多行文字默认仍粘贴在当前格中。无法解析的 TSV 按格内文本粘贴，不丢弃内容。
- 每次插入、对齐或矩阵粘贴为一次独立撤销；只读和输入法保护与其他结构操作一致。

## 复制、移动与退出

- 右键菜单按「复制表格数据」「行操作」「列操作」分组。
- 当前行、当前列和整表均可复制为 Markdown 或 TSV。Markdown 行和整表保留源码，Markdown 列导出为包含表头和对齐分隔行的单列表格。
- TSV 使用渲染文字，去除 Markdown 标记并保留格内换行；制表符、换行、双引号及空字段按 TSV 引号规则编码。整表和整列包含表头。
- 应用内剪贴板附带格子数据类型：普通粘贴可以恢复多格 Markdown 或 TSV；选择「粘贴到当前单元格」仍只粘贴文本。外部剪贴板优先读取 TSV 类型，兼容仅提供 TSV 字符串或 UTF-8 字节的应用。
- 数据行可上移／下移，表头固定；列可左移／右移，表头、数据和对齐一起移动。边界操作置灰。
- 「在下方创建行副本」复制当前行内容；复制表头时创建普通数据行，不创建第二个表头。
- 移动及创建副本均为一次撤销，完成后聚焦目标位置。
- 菜单可退出到表格前／后；工具栏和 Esc 退出到表格后。必要时建立正文空白段落，避免后续输入破坏表格。只读时仅定位，不修改文档。

## 布局与性能

- 短列按实际内容收窄；长列优先利用正文宽度，换行后按整行最高单元格设置行高；最低阅读宽度仍放不下时内部横向滚动。
- 列宽采用当前字号的字体测量及像素取整；活动格按源码内容测高。同表内输入固定列宽，离开表格及窗口、字号变化时重排。
- 保留 RichTextFX 行虚拟化、当前单元格测量缓存、弱引用可见节点及行号索引。水平滚动更新位移，不重建表格。
- 后台解析生成行内展示数据；JavaFX 测量按帧约 4ms 协作预算分批处理，完整表格布局就绪后统一应用。
- 工具栏显示、鼠标移动、滚动和输入不触发全表源码格式化；仅主动点击「优化表格」时执行格式化，相同结果不产生撤销记录。
- 后台回填校验文档版本，销毁及解绑取消任务、释放缓存；沿用现有大文档限制。

## 人工验收重点

- 空格连续输入、删除至空后重输、缺列首输、新增行列后输入，检查保存源码与预览一致。
- 首尾 Tab 退出后输入正文；跨屏和超宽表格 Tab 导航；窗口缩放后焦点、光标、选区正确。
- 引用／列表表格、普通表格后接引用、缺列／多列、单列及仅表头；增删和格式化保留内容与容器。
- `# 标题`、`---`、引用链接、转义竖线、行内代码中的 `<br>`、`<BR />`、中文输入法。
- 只读快捷键、结构操作后撤销重做、搜索定位、切换文档，以及 100／1,000 行表格的连续输入与滚动。
- 在中间行列插入、表头操作、三种列对齐；粘贴 2×3 TSV、带引号换行的 TSV、空字段、末尾换行及仅换行分列，检查扩容和一次撤销。
- 复制行／列／整表的两种格式，粘贴到正文、另一张表及电子表格；检查样式、换行、引号和末尾空行。
- 行列移动到边界、创建行副本、移动后撤销重做；在文档首尾通过菜单、工具栏和 Esc 退出后输入正文。

4ms 是测量调度预算，不作为未经实测的帧率保证。不新增自动化测试，不主动运行 Gradle。
