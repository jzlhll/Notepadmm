# 当前文档 Markdown 目录

## 功能与解析

“当前文档”Tab 始终显示可换行的文件路径；当文件为 `.md` 或 `.markdown` 时，使用虚拟化 `ListView` 显示目录，否则清空目录。

- 识别 1～6 级 ATX 标题，行首允许最多 3 个空格，`#` 后必须为空白或行尾。
- 去掉标题两端空白和可选的关闭 `#`，忽略反引号或波浪线围栏内的伪标题。
- 标题每深一级增加 `12px` 左缩进，点击后跳转到对应行。
- 直接遍历字符和换行位置，不用 `split()` 或 `String.lines().toList()` 生成整篇行集合。
- 结果仅保存级别、标题和行号；新旧结果一致时不重设列表。

## 门槛与刷新

目录与语法高亮共用 `EditorAreaMgr.isRealtimeProcessingLimitReached()`。源文件字节数或当前正文字符数达到 2 MiB，或正文达到 10000 行时，不获取全文快照、不解析并立即清空目录；回到门槛内后可恢复刷新。

- 复用 `EditorAreaMgr.textChanged`，不重复订阅 `plainTextChanges()`。
- 每次输入立即停止 `PauseTransition`、通过 `Future.cancel(true)` 中断解析并使旧请求失效，然后重新计时 2 秒。
- “当前文档”Tab 未显示时仅标记失效，不取快照；重新显示时立即刷新。
- 切换或关闭文件、隐藏工作区、销毁页面时，移除旧监听、取消任务并使已投递结果失效。

## 线程与结果校验

JavaFX 主线程负责门槛检查、获取不可变文本快照、管理监听和更新界面。后台线程逐行扫描快照，每行检查中断状态，并生成不可变标题列表。

结果回到主线程后，仅在当前编辑器、`contentVersion`、请求编号、Tab 可见性和大文件门槛全部仍有效时应用，否则直接丢弃。
