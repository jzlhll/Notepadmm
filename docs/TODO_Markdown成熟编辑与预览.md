# TODO：Markdown 成熟编辑与预览

## 目标与现状

面向日常笔记和技术文档，对齐 Typora 90% 以上常用的显示与编辑体验。完成前两批的基础体验与可靠性验收后再评估成熟度，不以代码数量或语法覆盖率推断体验分数。

已接入共享 AST／结构快照、ATX／Setext 标题与大纲、引用和列表的段落装饰、任务切换、结构键盘操作、格式菜单、源码切换和完整排版预览。原生预览中，解析确认的标题、引用、强调、删除线、行内代码、链接及闭合围栏的语法标记默认零宽收起，光标进入对应结构或选区覆盖时展开；搜索命中的标记保持可见。显示层使用等长零宽排版占位保留 UTF-16 命中索引，不向源码写入隐藏字符。列表项目符号、未闭合围栏及尚未原生渲染的公式等内容保留可编辑源码。

技术文档能力已接入常用代码语言与围栏工具、图片附件导入／截图粘贴／拖入／宽度设置／重试、另存为相对路径迁移、表格创建／格内格式／链接／缩略图／富文本和截图粘贴、本地文档和标题锚点跳转、HTML 粘贴转 Markdown、多格式复制、字数统计及 HTML 导出。完整排版预览与导出共用公式、脚注、`[TOC]`、高亮、上下标、Front Matter、有限 HTML 和 Mermaid 流程图／时序图／甘特图的输出规则；公式与图表库离线提供。

Markdown（`.md`／`.markdown`）的实时处理阈值为 80,000 行、磁盘文件 10 MiB 或编辑中文本 10,485,760 个 UTF-16 单元；任意一项达到阈值时降级为源码编辑。其他文件类型保持原有大小配置及 10,000 行阈值。打开、重载、首次保存、另存为和重命名时按当前文件类型更新阈值；这些数值属于保护阈值，不代表已完成性能验收。

刷新采用块结构扫描、行内解析缓存与界面差量更新。CommonMark 保留全文块结构扫描，确保围栏、列表、引用定义和脚注的跨段语义正确；未变化的段落复用行内解析结果，并按当前源码位置复制节点，旧快照不被修改。查询过引用定义的段落、未知扩展节点和超出缓存预算的内容正常重解析。缓存保留相邻两个文档版本；行内缓存限制条目数和文本量，代码块高亮按内容与源码映射缓存并限制容量。

原生段落样式与代码块背景由同一结构快照统一应用，按编辑位置平移段落缓存，只更新受影响或排版变化的段落。标记展开状态独立于语法高亮，避免刷新时反复收起和展开。图片保留未修改项的节点、加载状态与尺寸，异步回填校验图片身份，加载监听按项释放。表格在内容、格式、字体及宽度未变化时复用布局；Mermaid 复用未变化的图表与预览，尺寸变化只调整布局。源码模式和大文档降级统一清理这些呈现。

解析适配基于 commonmark-java 0.30.0，行内缓存通过解析器工厂包装默认 `InlineParserImpl`。内部实现仅在 Java 适配入口访问，Kotlin 缓存使用公开的 `InlineParser` 接口；Java 编译参数与模块启动参数均仅向 `atools` 导出该内部包，开发运行和打包共用启动配置。升级 CommonMark 时须核对默认行内解析器及上下文接口。上述策略未复刻 Typora 未公开的内部算法，也不等同于跳过未变化区域的全文块级增量解析。

完整排版预览位于编辑器右键菜单；双击内容回到对应源码块，任务勾选写回原文。原生编辑区保留完整源码和字符索引，按编辑位置展开语法标记；复杂技术内容在完整预览中排版，并非全部已达到原生区的就地呈现效果。前两批仍有以下实现和验收缺口，不能标为整批完成。

## 第一批：日常正文与基础交互收口

- [ ] 原生正文补齐列表标记宽度与自动折行的悬挂缩进；引用竖线／背景贯穿同一块。多段、松紧列表、非 1 编号、混合嵌套、省略引用前缀及引用内图片／表格／代码，保持正文对齐和光标可见。
- [ ] 补齐替代呈现与源码的逐字符定位及跨块选区；核对方向键、Home／End、全选、搜索结果和模式切换后的光标与滚动位置，避免隐藏行抢光标或跳行。
- [ ] 验收语法标记收起／展开的零宽边界：标题首字、嵌套强调、链接尾部、代码保护空格、跨行选区、拖选、中文输入法和搜索跳转；源码复制、保存及撤销不能混入显示层占位字符，源码模式须恢复完整标记。
- [ ] 验收结构操作的复杂边界：多段列表项续写、空嵌套列表退层、引用中的嵌套代码、Setext 标题后进入正文、列表类型转换与跨块选区添加／解除格式；每次操作保持内容并可单次撤销。
- [ ] 验收包含多处 Setext 标题的批量转换，完整保留选区范围及空白分隔；正文和表格内带边界反引号、首尾空格的行内代码应可连续添加／取消格式。
- [ ] 在界面上验收任务点击、软／硬换行、转义／实体、未完成语法、中文输入法、只读、撤销／重做、查找／替换及多行粘贴；显示变化不能写入文本撤销链。
- [ ] 验收浅／深色主题中的标记对比度和选区可读性；阅读宽度、行高、字体、缩放、行号显隐及窗口变化不能遮挡内容。新建、首次保存为 Markdown、另存为、标签切换和保存重开应正确绑定。

语法以 CommonMark 为准，补齐 GFM 表格、删除线、任务列表和自动链接；显示、目录和编辑共用解析结果。预览保留原始标记、空白、尾空格和换行，不自动整理源码。链接采用 Ctrl／⌘ 点击打开，普通点击用于编辑。

验收：普通笔记能连续输入、阅读和修改。覆盖六级标题、多层引用、引用中的列表、列表中的代码、折行任务、强调组合、链接和分隔线；全过程不丢内容、不跳光标。

## 第二批：技术内容与工作流收口

- [ ] 补齐原生区的行内图片／文字混排，以及引用、列表内图片与其他块的统一布局；公式、脚注、目录、Front Matter、有限 HTML 的原生呈现与直接编辑范围应明确，不能只靠单独预览窗口认定体验完成。
- [ ] 验收图片的相对路径、中文／空格／括号路径、引用式图片、尺寸重复修改、失败重试及远程加载；另存为后的路径与选区、撤销和保存状态一致，附件异步导入不覆盖后来输入。普通文件移动后，以当前文档目录解释相对路径；移动时需同时保留对应附件目录结构。
- [ ] 验收代码围栏补全、引用／列表中的代码缩进、语言切换、复制、退出及长行横向查看；高亮不能覆盖正文、转义内容或旧版本。
- [ ] 收口正文与表格间的选择和搜索；验收富文本／HTML 表格／截图粘贴、异步图片导入、剪贴板、撤销和中文输入一致性，以及格内链接、图片失败、格式切换、键盘导航、行列编辑和 TSV。
- [ ] 验收中文／重复标题锚点、跨文档相对链接、目录跟随、脚注编号／回跳、公式错误定位、HTML 折叠／注释及 Mermaid 错误回退；未识别或未完成的内容保持可编辑源码。
- [ ] 验收 Mermaid 源码与图形模式的常显顶部操作栏：上下相邻标题、正文和表格不被遮挡；横向滚动源码后按钮仍可见，缩放、窄窗口、多图连续排列及模式切换时占位与裁剪正确。
- [ ] 验收 HTML 粘贴、源码／纯文本／格式化复制、正文／选区统计及导出内容一致性。基础 HTML 导出保留附件引用，依赖文档目录中的附件；独立打包与复杂打印排版不属于该入口。
- [ ] 验收选区复制的全文引用上下文：引用链接、引用图片、脚注及脚注间引用应正确输出，仅携带实际引用的脚注，不包含无关定义。
- [ ] 验收多张 HTML 表格与表外文字、图片、表题的混合粘贴；独立表格以矩阵写入，其他片段以格内 Markdown 完整保留。
- [ ] 验收完整预览在首次保存、另存为及重命名后的重新绑定；正文不变也应刷新标题、图片基准目录和 Markdown 支持状态，旧路径渲染结果不得回填。
- [ ] 对常规长笔记、连续输入、窗口缩放、宽表格、多图片与图表混排做性能和生命周期验收；切换／关闭标签与预览窗口后释放任务、缓存及监听，旧结果不能覆盖新内容。
- [ ] 使用 Vditor 中文综合示例复测连续输入、退格、跨段粘贴与滚动；重点确认正文输入不反复加载未变化的 Mermaid，标记展开不与高亮互相重置，增删换行后的段落和图表位置正确。性能改善需以开发版实际交互和耗时采样确认。
- [ ] 验收行内缓存与常规解析的一致性：段落前方增删换行、引用／列表缩进、表格格内格式、转义、代码、公式、引用链接定义与脚注修改；旧快照的节点和源码坐标不得被新版本改写。验收新模块启动参数在开发运行和发布包中的生效情况。
- [ ] 验收混淆发布包中的完整预览桥接：双击回源码、任务勾选、链接打开和代码复制均可用。

扩展范围：行内 `$…$`、独立 `$$` 围栏块公式；脚注 `[^标签]`；目录 `[TOC]`；高亮 `==…==`；无空白片段的 `^…^`／`~…~` 上下标；开头 YAML Front Matter。Front Matter 支持 `---` 开头及 `---`／`...` 结尾，原生区使用浅灰背景和灰色等宽文字，保持元数据原文；闭合分隔符默认收起且不占行高，光标进入、选区覆盖或分隔符命中搜索时恢复显示，未闭合块保留分隔符。完整预览与 HTML 导出使用同样的元数据块内容。HTML 支持常用 `br`、`img`、`u`、`sub`／`sup`、`details`／`summary`，过滤脚本和自定义 CSS，预览／导出不显示注释正文。图片宽度使用受限整数 `width`。

验收：常见 README、开发文档以及截图、表格、公式、图表笔记能正确显示和修改；复制粘贴、保存重开及导出内容一致。前两批的基础缺陷不能移到第三批等待确认。

## 第三批：边缘复杂任务，逐项确认后实施

本批都是边缘、复杂或专项任务，不默认整批实施。每一项开始前，必须逐项确认实际用途、支持范围、兼容性和实现成本，再决定实施或后置。

- [ ] Mermaid 类图。
- [ ] Mermaid 状态图及其他扩展图表，具体类型分别确认。
- [ ] PDF 导出与打印排版，包含分页、宽表格、公式、图片及图表的输出一致性。
- [ ] 完整 HTML／CSS、嵌入媒体及特殊 Typora 扩展兼容；具体标签和语法分别确认。
- [ ] 超大文档的块级增量解析、可见区域预览与分级降级；先确认目标大小和性能要求。
- [ ] 专注模式、打字机模式及高级主题定制，分别确认。

验收：按每项确认的范围验收。最终 90% 目标以常用文档的显示、编辑、剪贴板、保存和输出流程衡量，性能结论以实测为准。
