# TODO：Markdown 成熟编辑与预览

## 目标与现状

面向日常笔记和技术文档，对齐 Typora 90% 以上常用的显示与编辑体验。优先完成前两批必需能力；第三批按实际用途逐项选择，不能以边缘功能数量代替基础体验验收。

当前代码层面的体验估计约 55%（50%～60%），不是实测评分。已有基础高亮、表格编辑、独立图片预览、部分代码高亮、流程图／时序图和标题目录；主要差距是普通正文缺少统一的块排版、语法标记弱化和结构化编辑。

基础语法以 CommonMark 为准，补齐 GFM 表格、删除线、任务列表和自动链接；公式、脚注、目录等扩展按本文明确的范围支持。显示与编辑共用解析结果，不用独立正则重新判断语法；保留原始标记、空白和换行，预览不自动改写源码。

## 第一批：完成日常正文显示与编辑

- [ ] 同一文档版本共用 Markdown AST 和结构快照，记录源码／标记／正文范围、父子关系及标题级别、列表编号、任务状态；显示、目录和编辑操作使用同一语义。
- [ ] 统一 H1～H6（含 ATX／Setext）、普通段落及分隔线的字号、字重、段距和主题样式；区分 Setext 标题、分隔线与列表标记，空行和自动折行不改变块结构。
- [ ] 引用块支持 `>`、`>>`、多段引用和合法的省略前缀续行；按嵌套层级显示左侧竖线、缩进、内边距及轻微背景区分。竖线贯穿同一引用块，折行正文对齐；引用内的标题、列表、代码、图片和表格保留各自排版，背景和装饰不遮挡光标、选区或内容。
- [ ] 列表支持 `-`／`+`／`*`、有序列表的 `.`／`)` 及非 1 起始编号；统一标记宽度、正文缩进和续行对齐。正确处理松紧列表、跨行／多段列表项、混合嵌套及列表与引用的组合，显示编号不自动改写已有源码。
- [ ] 任务列表支持 `[ ]`／`[x]`／`[X]`、嵌套和折行；复选框对齐正文，可点击切换且只修改对应状态字符，进入同一撤销链；只读时禁止修改，勾选状态不能仅用颜色表达。
- [ ] 明确软换行、至少两个尾空格／反斜杠硬换行及 Shift+Enter 行为，显示与导出采用一致策略；正确显示转义字符、实体和字面符号，保留影响语义的尾空格。
- [ ] 明确粗体、斜体、粗斜体、删除线与行内代码的显示；支持星号／下划线强调、嵌套组合和多反引号代码跨度，代码使用等宽字体与独立背景，内容不再解析 Markdown；未配对标记保留为可编辑文本。
- [ ] 代码块的基础显示纳入本批：支持反引号／波浪号围栏和缩进代码，使用等宽字体、背景与块间距，保留空白和缩进；长行可横向查看，围栏未闭合时仍可输入，引用／列表中的代码正确缩进。
- [ ] 统一 Enter、Tab、Shift+Tab、Backspace 的结构操作：列表续接／拆分、编号、增减层级及空项退出；新任务项默认未勾选。引用 Enter 延续当前层级，空引用退出一层，Backspace 可解除前缀；标题后进入正文。选区批量添加／解除列表或引用保持内容，单次操作可完整撤销。
- [ ] 提供标题、粗体、斜体、删除线、行内代码、列表、引用和链接的常用菜单／快捷键；支持选中文字应用／取消格式，以及无选区时插入标记并定位光标，多行操作不破坏已有嵌套。
- [ ] 链接支持行内链接、完整／折叠／简写引用式链接、尖括号链接、常用裸网址及邮箱；正确处理链接标题、转义括号和中文地址。支持插入、修改、解除、复制地址及 HTTP(S)／邮件链接打开，明确编辑点击与打开动作，缺失引用定义保留原文。
- [ ] 正文中的 `#`、`*`、`>`、反引号等语法标记采用接近所在区域背景、但仍可辨认的低对比度颜色，保留字符占宽、光标命中、选择和编辑能力，不使用透明字符或零宽隐藏。颜色通过主题变量管理，兼顾浅色／深色主题和选区背景；仅弱化解析确认的语法标记，转义字符和代码中的字面符号正常显示。
- [ ] 统一实时预览／源码模式；普通正文保留真实字符位置，表格、图片、图表等替代呈现建立显示位置与源码位置映射。点击定位、方向键、Home／End、跨块选择、全选、搜索和滚动位置一致，支持普通文字及 Markdown 源码复制粘贴。
- [ ] 共用主文档撤销链，保护中文输入法组合输入、只读状态和保存源码；输入未完成语法时保持可编辑，渲染失败能回到源码，显示变化不产生文本撤销记录。
- [ ] 查找／替换能定位正文、语法标记和链接地址，替换后预览与目录同步；撤销／重做、选区缩进和多行粘贴保留正确的源码位置与结构。
- [ ] 提供舒适的阅读宽度、行高、段距、字体、主题、缩放及行号显隐；窗口变化不造成正文或光标遮挡。新建、首次保存为 Markdown、另存为和切换文件后能力正确绑定。

实施顺序：先完成“标题＋嵌套列表＋引用”的统一排版、低对比度标记和结构操作，再推广。区分源码行与 Markdown 段落，统一段落布局和装饰入口；正文语法标记持续显示，不因预览或焦点切换改变占宽。

验收：普通笔记能连续输入、阅读和修改；覆盖六级标题、多层引用、引用中的列表、列表中的代码、跨行任务项、强调组合、链接和分隔线。语法标记在浅色／深色主题下稍微可见、可直接定位编辑，选中后仍可辨认；嵌套结构、跨块选择、撤销、中文输入法、模式切换及保存重开均不丢内容、不跳光标。

## 第二批：完成技术文档和常用内容工作流

- [ ] 图片支持行内／独立段落和引用式图片、替代文本与标题、截图粘贴、拖入插图、附件目录、相对路径、尺寸设置及表格内呈现；文档移动／另存为后的图片引用有明确处理，加载失败显示替代文本并可重试，远程加载不阻塞输入。
- [ ] 代码块补充 JS／TS、Python、JSON、Shell、SQL、YAML 等常用高亮，以及创建代码块、围栏补全、代码缩进、语言选择、复制和退出到正文；长代码行可独立横向滚动。
- [ ] 表格提供创建入口及键盘导航，补齐格内链接打开、图片和格式操作；正文与表格间的选择、搜索、剪贴板、撤销及中文输入一致，复用已有行列编辑和 TSV 能力。
- [ ] 支持文内锚点、本地文档链接及相对路径跳转；目录共用 AST，正确显示 ATX／Setext 标题、清除格式标记并跟随当前章节；明确中文／重复标题的锚点规则，支持 `[TOC]`。
- [ ] 支持行内／块级公式、脚注定义及编号／回跳、高亮、上下标、Front Matter 的识别与编辑；定义各扩展语法的启用范围，未识别内容保留源码，公式错误可直接定位修改。
- [ ] 兼容常用 `<br>`、`<img>`、`<u>`、`<sub>`／`<sup>` 及 `<details>`／`<summary>` 的有限 HTML 显示与折叠；识别 HTML 注释，编辑时可定位，预览和导出不显示注释正文。Front Matter 与正文分开呈现，可展开编辑。
- [ ] 完善已有 Mermaid 流程图／时序图的编辑、错误提示和源码回退；普通代码块与图表切换不破坏围栏或撤销历史。
- [ ] 支持常见富文本／HTML 粘贴转 Markdown，明确普通粘贴与纯文本粘贴；支持复制为 Markdown、纯文本和格式化内容，以及基础 HTML 导出。
- [ ] 补正文／选区字数统计；对常规长笔记、连续输入、窗口缩放、宽表格、多图片及图表混排做性能与生命周期验收，避免旧解析结果覆盖新正文。

验收：常见 README、开发文档及带截图、表格、公式、图表的笔记能正确显示和直接编辑；复制粘贴、保存重开及 HTML 导出内容一致。前两批的基础交互和可靠性必须在本批内收口。
