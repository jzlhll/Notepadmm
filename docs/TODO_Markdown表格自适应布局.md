# Markdown 表格优化入口屏蔽与自适应布局

## 一、阶段安排

- **当前阶段：屏蔽“优化表格”功能。** 不显示优化提示，不启动对应后台解析，不触发表格格式化；保留实现及文案。
- **后续阶段：实现自适应单元格布局。** 所有识别到的表格自动采用固定列边界、格内换行及格内编辑。
- 两个阶段独立交付；表格优化开关仅控制格式化功能，不限制自适应布局。

## 二、当前阶段：屏蔽优化入口

- 在 `NotepadController` 设置默认关闭的表格优化开关，统一控制管理器启用入口。
- 关闭状态下不创建 `MarkdownTableOptimizeManager`；已有实例执行销毁，停止监听、解析调度及弹窗。
- 表格继续保持 Markdown 原文编辑与高亮，图片、代码块及目录功能保持正常。

## 三、后续阶段：自适应列宽

### 宽度分配

- 可用宽度取编辑区实际视口，扣除行号、左右边距、表格边框及滚动条占位；读取实际布局尺寸，避免重复扣除。
- 每列理想宽度取表头与全部单元格中最长内容的实际字体测量宽度，加左右各 8px 留白。
- 最小列宽为两个字号宽度加留白；长列的最低可读宽度为八个字号宽度加留白，短列以自身理想宽度为限。
- 按可用空间等分列宽，达到理想宽度的短列固定，其余空间继续由长列等分。全部内容都能放下时，表格保持紧凑。
- 最低可读宽度之和超过视口时，采用最低可读宽度，整张表格共享水平滚动位置和滚动条，不撑宽编辑区。

### 换行与尺寸变化

- 同一列共用宽度；同行高度取各单元格换行后的最大高度，内容顶端对齐，竖向边界保持一致。
- 长内容完整显示，允许长单词、URL 和连续中文在字符边界折行，不显示省略号。
- 保留 Markdown 声明的左对齐、居中及右对齐。
- 窗口、字体、字号和编辑区边距变化时重新计算列宽。
- 焦点位于表格内时，普通输入只调整行高；离开表格后更新内容对应的列宽。窗口缩放仍即时适配。

## 四、后续阶段：格内编辑与集成

### 编辑行为

- 单击单元格直接编辑，展示与编辑使用相同列宽，编辑高度随内容增长。
- Tab／Shift+Tab 切换单元格，表格边界处返回正文。
- 自动折行仅属于显示布局，不向文件插入换行；主动输入或粘贴的换行使用 `<br>` 保存，内容中的竖线使用转义形式保存。
- 修改同步到主文档对应范围，保存、撤销、重做和修改状态统一由主文档管理。
- 中文输入法组合输入期间保持编辑节点、光标及选择稳定；只读状态禁止格内修改。
- 本阶段包含已有单元格编辑，不增加拖动列宽、合并单元格及增删行列工具。

### 技术集成

- 自适应布局由独立的表格布局管理器负责，维护表格、行、单元格及原文范围映射。
- 布局计算与文本格式化分离，窗口尺寸变化不改写正文。
- 采用逐行内嵌呈现，复用段落虚拟化；表格段落由单元格视图负责显示和命中，Markdown 分隔行作为表头边界表达。
- 行号、图片与表格共用统一的段落图形组合入口，避免多个管理器相互覆盖。
- 搜索定位、光标及选择范围映射至对应单元格；正文范围复制保留完整 Markdown。
- 沿用文档版本校验与后台解析调度；表格语法失效或触发大文档处理限制时显示完整原文。
- 文件格式及外部公共接口保持兼容。

## 五、验收场景

- 当前阶段：打开文档、切换标签、刷新文件及光标进入表格，均无“优化表格”提示，不触发表格格式化。
- 短列与长列混合：序号等短列紧凑，长说明列获得剩余宽度。
- 多个长列：列宽合理分配，内容格内换行，同行等高，竖线对齐。
- 全部短列：表格不强制撑满窗口。
- 窗口缩放、多列及大字号：布局自适应，横向滚动仅作用于对应表格。
- 输入、中文输入法、复制粘贴、搜索、撤销重做及保存重开：内容完整，光标与原文位置对应正确。
- 格式标记、转义竖线、空单元格及代码块内的表格样式文本：语义与文档内容保持一致。
