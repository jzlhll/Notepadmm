## 显示范围

打开 `.md`／`.markdown` 文件后，原生编辑区保留完整源码，按光标、选区和搜索状态展开或收起语法标记。普通列表、任务和引用使用原生段落排版；包含图文混排、表格、公式等技术内容的容器，以及技术段落和折叠详情使用编辑区内的块预览。块预览双击回到对应源码节点；光标进入、选区覆盖或命中搜索时恢复整个块的源码。块预览复用受限 HTML 排版，不属于逐字符直接富文本编辑。右键菜单中的完整排版预览提供更完整的技术文档排版；双击预览内容回到对应源码块，任务勾选写回原文。源码模式、原生预览、完整预览是不同入口，不能用完整预览的支持范围代替原生编辑区的支持范围。

显示层使用等长零宽排版占位保留 UTF-16 命中索引，不向源码写入隐藏字符；搜索命中的标记保持可见。未闭合围栏及尚未原生排版的内容保留可编辑源码。

| 功能 | 原生编辑区 | 完整预览／HTML 导出 |
| --- | --- | --- |
| 六级 ATX／Setext 标题、大纲、强调、删除线、链接、行内代码 | 已接入；语法标记按编辑状态展开 | 已接入 |
| 引用、有序／无序列表 | 普通内容使用原生分层缩进及引用装饰；包含技术内容的容器使用块预览 | 已接入 |
| GFM 任务列表 | 复选框可点击，写回 `[ ]`／`[x]` | 完整预览可点击；导出保留任务状态 |
| 反引号包裹的状态短码 | 独立 `[ ]`／`[x]`／`[X]` 显示为扁平状态图标，表格内一致 | 使用相同图标；保留状态文本用于复制 |
| 表情短码 | 已接入表情转换 | 已接入 |
| 代码块 | 围栏／缩进代码、常用语言高亮、语言切换、复制及退出 | 代码高亮已接入 |
| 图片 | 独立图片、HTML `img`、表格缩略图及块预览中的图文混排、列表／引用内图片；支持本地及 HTTP／HTTPS | 支持图片及文字混排；导出保留图片引用 |
| GFM 表格 | 可直接编辑单元格、行列和对齐 | 排版输出 |
| Mermaid | 离线流程图、时序图、甘特图；源码／图形切换 | 离线排版输出 |
| YAML Front Matter | 文档开头 `---`，结尾 `---` 或 `...`；灰色等宽元数据块，分隔符按编辑状态展开 | 输出元数据块 |
| HTML `details`／`summary` | 块预览支持摘要折叠、嵌套及受限 HTML／Markdown 内容；编辑时恢复源码 | 支持折叠详情及受限 HTML |

| HTML 注释与其他 HTML | 注释以简短占位显示，双击恢复源码；其他内容按受限 HTML 排版或保留源码 | 注释不显示；过滤脚本及自定义 CSS，保留受限 HTML |

代码高亮已覆盖 Java、Kotlin／kt、Swift、Objective-C、C／C++、Go、Groovy／Gradle、JavaScript／TypeScript、Python、JSON、YAML、XML／HTML、CSS、Bash／Shell、SQL 等常用语言及别名。字符串、关键字、注释等使用独立配色；语言选择对话框同步列出已支持语言。高亮用于阅读，不等同于编译器语法检查。

扩展语法包括行内 `$…$`、独立 `$$` 围栏块公式、脚注 `[^标签]`、目录 `[TOC]`、高亮 `==…==` 和无空白片段的 `^…^`／`~…~` 上下标。Front Matter 位于文档开头，闭合分隔符默认收起且不占行高；光标进入、选区覆盖或分隔符命中搜索时恢复，未闭合块保留分隔符。受限 HTML 包括 `br`、`img`、`u`、`sub`／`sup`、`details`／`summary`；图片宽度使用受限整数 `width`。

## 正文快捷键

下表 `快捷键` 表示 macOS 的 `⌘` 或 Windows 的 `Ctrl`。适用于可编辑的 Markdown 正文；表格单元格使用独立规则，见下一节。只读和输入法组合输入期间不执行内容修改。格式命令统一保护代码、公式、HTML 和 Front Matter；跨选区涉及字面内容时不改写。大文档降级后暂停格式命令，纯文本粘贴和模式切换仍保留。

| 操作 | 按键 |
| --- | --- |
| 添加／取消粗体 | 快捷键 + B |
| 添加／取消斜体 | 快捷键 + I |
| 添加／取消行内代码 | 快捷键 + 反引号键 |
| 编辑／插入链接 | 快捷键 + K；地址留空可移除链接 |
| 添加／取消删除线 | 快捷键 + Shift + X |
| 一级至六级标题 | 快捷键 + 1～6 |
| 恢复正文 | 快捷键 + 0 |
| 引用操作 | 快捷键 + Shift + Q |
| 无序列表操作 | 快捷键 + Shift + L |
| 源码／原生预览切换 | 快捷键 + Shift + M |
| 纯文本粘贴 | 快捷键 + Shift + V |
| 续写列表／任务／引用、延续代码缩进 | Enter；空列表项退出或退层，新任务默认未完成 |
| 硬换行 | Shift + Enter；代码块中保持代码换行规则 |
| 缩进／减少缩进 | Tab／Shift + Tab，按四个空格处理 |
| 删除当前列表／引用前缀 | 在正文起始位置按 Backspace |
| 上移／下移选中行 | Alt + ↑／↓ |
| 打开链接 | 快捷键 + 点击；普通点击用于编辑 |

撤销／重做、查找／替换、保存、剪切／复制／粘贴沿用通用编辑器入口。格式、代码块、表格及图片还提供右键菜单。顶部字体按钮旁的列表图标可打开快捷键速查窗口，分别列出正文与表格现有键位；正文格式菜单同步显示对应键位。没有新增快捷键，也没有 Markdown 快捷键自定义入口。

## 在线图片

HTTP／HTTPS 图片加载已接入共用请求逻辑，显式处理跨协议及相对地址重定向，最多跟随 5 次跳转；发布包保留 `jdk.crypto.ec` 兼容模块；JDK 25 的 SunEC 实现位于 `java.base`。代码修正已实现，更新后的实际安装包显示仍待验收。

| 场景 | 当前实现与边界 |
| --- | --- |
| 独立成段 `![说明](https://…/image.png)` | 原生区异步加载；支持 HTTP 和 HTTPS |
| 独立 HTML `img` | 支持远程地址及受限 `width`／缩放设置 |
| 引用／列表中的独立图片 | 在块预览内统一排版，后台加载并支持失败重试 |
| 表格中的图片 | 加载远程缩略图；并发最多 4 个，连接／读取超时各 8 秒，单张读取上限 20 MiB |
| 同一段文字与图片混排 | 编辑区内块预览及完整预览均支持 |
| 加载失败 | 有占位提示；点击失败占位可重试 |
| 图片格式与访问条件 | 依赖各显示入口的解码能力；远程 WebP／SVG 等需分别验收。没有自定义认证／防盗链请求头入口，图片直链与网页地址须区分 |
| HTML 导出 | 保留远程引用；不自动下载为本地附件或打包进独立文件，离线阅读仍依赖图片可用性 |

正文和表格远程图片均在后台读取，连接／读取超时各 8 秒，单图读取上限 20 MiB；每一跳均保留状态、目标地址和读取日志，下载完成后再交给 JavaFX 解码。应用共用按链接索引的内存缓存：缓存下载数据及各显示尺寸的解码图片，同一链接正在进行的下载合并等待，重定向原地址与目标地址映射到同一份数据。切换文档、重建节点或关闭标签不清空共用缓存；查询参数参与缓存键，片段不参与。缓存最多保留 128 个链接映射，下载数据和解码像素按约 64 MiB 预算淘汰最久未使用项；请求／解码失败不保留，退出应用后缓存释放。正文与表格共用最多 4 个后台工作线程，切换或关闭文档时取消所属任务；已经进入网络读取的任务在读取返回或超时后退出。正文索引仅弱引用图片，避免绕过共用缓存预算；单张正文解码限制约 400 万像素，排版仍使用原始尺寸，表格按 120 × 80 缩略图解码。缩略图淘汰仅处理已完成项，排队和加载中的占位保持回填与重试能力。运行时模块变化必须重新打包安装，`fastCopy` 不更新安装包内的 Java 运行时。

诊断日志写入 `~/.atools_notepadmm/log/`，搜索 `markdown image`，按 `request` 编号关联一次请求。正文记录文档、行号、地址、耗时、异步加载／解码异常链、重试及过期结果；正文与表格共用响应状态、内容类型、重定向和读取字节数日志；表格另记录文档清理取消。缓存命中记录 `cache hit`／`cache decoded hit`，下载合并记录 `cache wait shared download`；排查时应区分缓存复用、请求失败、收到非图片内容、解码失败和旧文档结果被丢弃。

人工检查使用公开 PNG／JPEG 图片直链，分别覆盖 HTTP、HTTPS、HTML 宽度、引用／列表、表格、文字混排、无效地址重试和文档切换；检查完整预览及导出是否保留预期图片引用。

验收：普通笔记能连续输入、阅读和修改。覆盖六级标题、多层引用、引用中的列表、列表中的代码、折行任务、强调组合、链接和分隔线；全过程不丢内容、不跳光标。

## 大文档与维护边界

Markdown（`.md`／`.markdown`）的实时处理阈值为 80,000 行、磁盘文件 10 MiB 或编辑中文本 10,485,760 个 UTF-16 单元；任意一项达到阈值时降级为源码编辑。其他文件类型保持原有大小配置及 10,000 行阈值。打开、重载、首次保存、另存为和重命名时按当前文件类型更新阈值；这些数值属于保护阈值，不代表已完成性能验收。

刷新采用块结构扫描、行内解析缓存与界面差量更新。高亮从不可变文档快照在后台读取全文样式；内容版本变化后提前停止旧版本的样式计算，避免继续合成最终不会显示的结果。复杂块范围按有序区间索引检查相邻项，收集过程不逐个扫描全部已有块。CommonMark 保留全文块结构扫描，确保围栏、列表、引用定义和脚注的跨段语义正确；未变化的段落复用行内解析结果，并按当前源码位置复制节点，旧快照不被修改。查询过引用定义的段落、未知扩展节点和超出缓存预算的内容正常重解析。缓存保留相邻两个文档版本；行内缓存限制条目数和文本量，代码块高亮按内容与源码映射缓存并限制容量。

原生段落样式与代码块背景由同一结构快照统一应用，按编辑位置平移段落缓存，只更新受影响或排版变化的段落。标记展开状态独立于语法高亮，展开范围随文本编辑平移，高亮回填只核对这些范围，避免扫描全文样式或反复收起和展开。图片保留未修改项的节点、加载状态与尺寸，异步回填校验图片身份，换源或离开文档时取消对应任务；窗口宽度变化同步调整图片与段落占位。表格在内容、格式、字体及宽度未变化时复用布局；测量、行高汇总、可见节点更新及其余段落样式回填共用每帧约 4 毫秒的协作预算，可见行优先，过期版本停止回填。预算在步骤之间检查，不强行中断单次文本测量或 JavaFX 排版；切换标签最多保留 4 份文档、合计 20,000 个单元格的测量数据，不保留离屏控件，内容版本或文件路径变化时失效。表格状态按源码区间匹配，避免逐表两两扫描。复杂块只展开受编辑影响的内容，未变化的块保留页面和折叠状态；普通正文编辑复用块 HTML，标题目录、引用定义、脚注上下文或块源码变化时重新生成。光标移动不重复扫描块内搜索样式、写入未变化的段落样式或同步只读状态。宽度或页面内容变化保留原测量高度，页面按帧合并测高并只回报变化值。表情及任务图标挂在原段落内，共用滚动、裁剪和缩放，布局及可见内容变化时才刷新；换行处理缓存上一轮可见段落，布局后直接读取 Flowless 可见单元格，表情与任务图标共用一次文字节点收集，不递归搜索编辑器节点树；表情着墨测量按字形与字体缓存，滚回已读段落不重复截图扫描。Mermaid 复用未变化的图表与预览，尺寸变化只调整布局。源码模式和大文档降级统一清理这些呈现。

块预览按完整块处理，单块最多 64,000 个 UTF-16 单元且少于 500 行；排版高度超过 30,000 像素时回退源码。同时最多挂载 8 个块预览，每块最多 8 张图片，超出时保留源码；页面准备在后台执行，仅随虚拟段落挂载，离屏释放 WebView 和图片任务；源码模式和大文档降级统一清理呈现。块内图片按约 400 万像素解码后提供给页面，图片格式受共用解码器限制；动画按解码帧呈现。块预览的首次加载、连续输入和多块混排尚待实际性能验收。

普通退格、正文点击、选区缩进与反缩进不获取全文结构快照。普通正文单光标换行通过只读快照核对行属性和完整前后文，确认只有当前普通正文行变化时不等待解析锁；无法确认时回到完整结构判断。列表续行、代码围栏补全和单光标缩进等依赖 AST 的结构命令仍同步查询当前版本，缓存命中直接返回；不使用可能过期的结构信息改写文档，也不引入异步按键队列。

完整预览在同一文档内更新时复用内容未变化的顶层块，单独更新源码坐标，保留阅读位置、折叠状态和已渲染的公式／图表；新增图片只在实际插入页面后加载。主题变化或首次引入尚未加载的技术渲染库时重建页面。HTML 容器在整篇输出后统一清理，支持跨 AST 块的嵌套详情结构。上下标在编辑区内块预览排版，源码编辑时保留 `^`／`~` 标记。上述机制不代表已有实际帧率和耗时测量结论。

解析适配基于 commonmark-java 0.30.0，行内缓存通过解析器工厂包装默认 `InlineParserImpl`。内部实现仅在 Java 适配入口访问，Kotlin 缓存使用公开的 `InlineParser` 接口；Java 编译参数与模块启动参数均仅向 `atools` 导出该内部包，开发运行和打包共用启动配置。升级 CommonMark 时须核对默认行内解析器及上下文接口。该策略不等同于跳过未变化区域的全文块级增量解析。
