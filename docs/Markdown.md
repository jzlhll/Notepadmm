# Markdown 功能、操作与待办

本文统一维护支持范围、快捷键和分批待办。目标是对齐 Typora 90% 以上常用显示与编辑体验，以日常笔记及技术文档工作流验收衡量；已有实现不等于通过界面、性能或发布包验收。

## 显示范围

`.md`／`.markdown` 编辑区保留完整源码，按光标、选区和搜索状态收放语法标记。普通列表、任务和引用采用原生段落；复杂容器和技术段落采用编辑区内块预览，双击、进入编辑或选择／搜索覆盖时恢复源码。独立表格使用单元格编辑器，容器内表格在源码中编辑。右键可打开完整排版预览，双击定位源码，任务勾选写回原文。块预览采用受限 HTML 排版，编辑仍在源码中进行。

| 功能 | 编辑区 | 完整预览／HTML 导出 |
| --- | --- | --- |
| 六级 ATX／Setext 标题、大纲、强调、删除线、链接、行内代码 | 原生样式及标记收放 | 已接入 |
| 引用、有序／无序列表、任务列表 | 原生排版；复杂容器用块预览；任务点击写回状态 | 已接入；完整预览可勾选任务 |
| 表情短码、反引号包裹的独立 `[ ]`／`[x]`／`[X]` | 表情／状态图标；状态示例不可点击切换 | 同款图标，保留复制文本 |
| 围栏／缩进代码 | 常用语言高亮、语言切换、复制、退出、长行横向查看 | 代码高亮 |
| 图片、HTML `img` | 本地／HTTP／HTTPS、宽度／缩放、失败重试、表格缩略图及复杂容器图文混排 | 保留图片引用 |
| GFM 表格 | 单元格格式、链接、行列编辑、对齐、键盘导航和粘贴 | 排版输出 |
| Mermaid | 离线流程图、时序图、甘特图，源码／图形切换 | 离线排版输出 |
| YAML Front Matter | 文档开头 `---`，以 `---` 或 `...` 闭合；元数据块及分隔符收放 | 输出元数据块 |
| 公式、脚注、`[TOC]`、高亮、上下标 | 技术内容使用块预览，编辑恢复源码 | 已接入；公式库离线提供 |
| HTML `details`／`summary`、注释及其他 HTML | 折叠详情与受限 HTML 块预览；注释占位可恢复源码 | 折叠详情；注释不显示，过滤脚本与自定义 CSS |

代码高亮覆盖 Java、Kotlin／kt、Swift、Objective-C、C／C++、Go、Groovy／Gradle、JavaScript／TypeScript、Python、JSON、YAML、XML／HTML、CSS、Bash／Shell、SQL 等及常用别名，语言选择对话框同步支持范围。

扩展语法为 `$…$`、独立 `$$` 围栏公式、`[^标签]`、`[TOC]`、`==…==` 和无空白片段的 `^…^`／`~…~`。受限 HTML 包括 `br`、`img`、`u`、`sub`／`sup`、`details`／`summary`；图片 `width` 使用受限整数。未闭合或未识别内容保留可编辑源码。显示层占位保持 UTF-16 索引，不向源码写入隐藏字符；原始空白、尾空格和换行不自动整理。

## 快捷键

下表“快捷键”为 macOS 的 `⌘` 或 Windows 的 `Ctrl`。正文格式命令保护代码、公式、HTML 和 Front Matter；跨选区涉及字面内容时不改写，只读、输入法组合输入和大文档降级期间不执行格式修改。模式切换与纯文本粘贴保留。

| 正文操作 | 按键 |
| --- | --- |
| 粗体／斜体／行内代码 | 快捷键 + B／I／反引号键 |
| 编辑／插入链接，空地址移除链接 | 快捷键 + K |
| 删除线 | 快捷键 + Shift + X |
| 一级至六级标题／正文 | 快捷键 + 1～6／0 |
| 引用／无序列表 | 快捷键 + Shift + Q／L |
| 源码／原生预览切换 | 快捷键 + Shift + M |
| 纯文本粘贴 | 快捷键 + Shift + V |
| 续写列表／任务／引用、代码缩进及围栏补全 | Enter；空项退出或退层，新任务默认未完成 |
| 硬换行 | Shift + Enter；代码块保持代码换行规则 |
| 缩进／反缩进 | Tab／Shift + Tab，四个空格 |
| 删除列表／引用前缀 | 正文起始位置按 Backspace |
| 上移／下移选中行 | Alt + ↑／↓ |
| 打开链接 | 快捷键 + 点击；普通点击编辑 |

| 表格单元格操作 | 按键 |
| --- | --- |
| 粗体、斜体、行内代码、删除线、纯文本粘贴 | 与正文相同 |
| 前后单元格导航 | Tab／Shift + Tab；首尾越界进入正文 |
| 在当前行下方插入数据行 | 快捷键 + Enter |
| 退出到表格后 | Esc |
| 撤销／重做 | 快捷键 + Z／Shift + Z；另支持快捷键 + Y 重做 |

表格右键“Markdown 格式 → 编辑链接”共用正文对话框，支持插入、修改和移除；格内不增加快捷键 + K，正文块级格式不用于格内内容。正文撤销、搜索、保存和剪贴板沿用通用入口；代码、表格及图片操作也有右键菜单。顶部字体按钮旁的列表图标提供正文／表格键位速查；尚无快捷键自定义入口。

## 第三批输出与后续范围

### 已实现输出

- **Markdown PDF**：正文右键“导出 PDF”，选择 A4 纵向／横向后保存；使用浅色纸面，隐藏操作按钮，展开折叠内容，等待图片、公式及 Mermaid 排版后输出。按文字行、表格行和图片边界分页，宽表格及技术内容缩放适应纸张，代码长行换行，页脚带页码。当前采用约 192 DPI 的页面图像，正文不可搜索／选择复制，链接不可点击；不依赖系统虚拟打印机。
- **普通文本打印**：TXT、LOG 及其他非 Markdown 文本右键“打印”，使用系统打印对话框的纸张、方向、份数及页码范围；正文使用黑字和 10 点字体，长行换行。分块文件打印已编辑正文及尚未加载的磁盘尾部，不只打印当前加载片段。
- **输出状态**：确认输出后获取文档快照，不要求先保存；可取消，失败清理本次资源。PDF 完整写入临时文件后替换目标，最多 1,000 页，沿用 Markdown 全文处理上限；图片共用受限下载缓存，按输出分辨率解码，单张最多 20 MiB，并受统一内存额度约束。图片加载失败或排版超时会终止导出。PDF 分页、中文、图片／公式／图表及 Windows／macOS 打印交互仍需运行验收。
- **发布依赖**：PDFBox 3.0.8 及其传递依赖随完整包分发；现有 `fastCopy` 只更新项目 JAR，不能补齐新增的第三方 JAR，首次加入 PDF 导出须完整重新打包。

## 图片与维护边界

- **在线图片**：正文、表格和块预览共用最多 4 个后台工作线程；连接／读取超时各 8 秒，单图上限 20 MiB，最多 5 次显式重定向。共享下载与各尺寸解码缓存，合并同链接并发请求；查询参数参与键，片段不参与，失败不保留。缓存上限 128 个链接映射、约 64 MiB；正文／块图片解码约 400 万像素，表格缩略图 120 × 80。切换文档不清空共用缓存，所属任务取消后，已进入网络读取的请求待返回或超时结束。
- **图片访问与导出**：没有自定义认证／防盗链请求头入口；使用图片直链。HTML 导出保留远程／本地引用，不自动下载或打包附件。诊断日志在 `~/.atools_notepadmm/log/`，搜索 `markdown image`，按 `request` 关联状态、重定向、读取字节、异常、重试、缓存及过期结果。
- **运行时兼容**：发布包保留 `jdk.crypto.ec`，JDK 25 的 SunEC 实现在 `java.base`。运行时变化需重新打包，`fastCopy` 不更新安装包内 Java 运行时；源码配置存在不代表安装包联网验收通过。
- **大文档降级**：Markdown 达到 80,000 行、磁盘文件 10 MiB 或编辑文本 10,485,760 个 UTF-16 单元之一时降级源码编辑。其他类型保持原配置及 10,000 行阈值；打开、重载、首次保存、另存为和重命名按当前类型更新。保护阈值不代表性能验收结果。
- **块预览预算**：单块最多 64,000 个 UTF-16 单元且少于 500 行，高度超过 30,000 像素回退源码；同时最多挂载 8 块，每块最多 8 张图片。后台准备页面，离屏释放 WebView 和所属图片任务；源码模式及大文档降级清理呈现。
- **刷新与缓存**：全文块结构扫描保证跨段语义；未变化段落复用行内解析，保留相邻两个版本并限制缓存。高亮按不可变快照计算、过期停止；标记展开独立于高亮，未变图片、表格、复杂块及 Mermaid 复用呈现。表格测量与回填按每帧约 4 毫秒协作处理，最多保留 4 份文档／合计 20,000 格测量数据，不保留离屏控件。
- **结构命令**：普通退格及正文点击避免获取全文结构；列表续写、围栏补全、缩进和格式命令需要当前版本 AST。已有快照直接使用；缺少快照时由 `MarkdownCommandRunner` 后台准备，等待期间按顺序保留编辑输入，回填前校验版本、文件及选区。该队列仍需连续输入及取消场景验收。
- **解析器兼容**：commonmark-java 0.30.0；Java 适配默认 `InlineParserImpl`，Kotlin 使用公开 `InlineParser` 接口。编译与开发／打包启动配置仅向 `atools` 导出内部包。升级时核对内部接口；行内复用不等同于全文块级增量解析。
